# Lotto 6aus49 – PWA personale

## Pubbllicarla gratis su GitHub Pages

1. Crea un account gratuito su https://github.com
2. Crea un nuovo repository pubblico, ad esempio `lotto-app`
3. Carica **tutti i file di questa cartella** nel repository:
   - `index.html`
   - `manifest.json`
   - `service-worker.js`
   - cartella `icons/` con le due icone
4. Vai in **Settings → Pages**
5. In **Source** scegli `Deploy from a branch`
6. Scegli `main` e cartella `/ (root)`, poi salva
7. Dopo 1-2 minuti apri l’indirizzo:
   `https://TUONOMEUTENTE.github.io/lotto-app/`

## Installarla su iPhone

1. Apri il link con **Safari**
2. Tocca **Condividi**
3. Scegli **Aggiungi alla schermata Home**
4. L’icona “Lotto 6aus49” si apre come app a schermo intero

## Installarla su Android

1. Apri il link con **Chrome**
2. Tocca il menu ⋮
3. Scegli **Installa app** oppure **Aggiungi alla schermata Home**

## Note

- L’app funziona offline dopo la prima apertura.
- Lo storico è salvato sul telefono.
- Usa **Esporta** per fare una copia di sicurezza dello storico e **Importa** per ripristinarla.
